### 🔧 Featured projects
 
**[Cuestomize](https://github.com/logicorg/cuestomize)** · Go · Kubernetes
A Kubernetes package manager that brings [CUE](https://cuelang.org)'s type safety into Kustomize. It runs as a KRM function, pulls CUE models from OCI registries, and can feed resources from the Kustomize stream into the model — type-safe manifests and validation without giving up Kustomize. I created it at Workday, where it was open-sourced, and now maintain it under [logicorg](https://github.com/logicorg).
 
**[IVFS](https://github.com/logicorg/ivfs)** · Go · Temporal · PostgreSQL
A personal-finance project built on a double-entry ledger, with Temporal workflows, per-user databases, a web UI and an MCP server. Design decisions are documented as [ADRs](https://github.com/logicorg/ivfs/tree/main/docs/adrs). Pre-alpha, and a playground for doing things properly.
 
**[ChatGPSP](https://github.com/lorenzofelletti/chat_gpsp)** · Rust · `no_std`
Chat with ChatGPT from a Sony PSP (2005 hardware). Runs on a real PSP over Wi-Fi, talking HTTPS to the OpenAI API — built on my networking crate below.
 
**[psp-net](https://github.com/lorenzofelletti/psp-net)** · Rust · [crates.io](https://crates.io/crates/psp-net)
A networking crate for the PSP: TCP/UDP sockets, TLS (via [embedded-tls](https://github.com/drogue-iot/embedded-tls)) and DNS resolution, so PSP homebrew can talk to the modern internet.
